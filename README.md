# OBS Clock Widget

[Open the OBS Clock Widget](https://obs-clock-widget.pages.dev/)

OBS Clock Widget is a free, privacy-friendly web app for creating customizable clocks and reload-safe event countdowns for OBS Browser Sources. Choose worldwide timezones, presets, colors, layouts, and more than 40 self-hosted fonts, then copy the generated permanent URL into OBS—no account, analytics, storage, or third-party runtime requests required.
